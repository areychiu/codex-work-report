A08 / 教學組工作台

08｜兼課教師名冊、聘任與文件進度

沿用已核對的教師身分、聯絡與授課資料，集中追蹤聘期、核准依據及應備文件。

目前狀態 已有介面；人員分類與關係仍待梳理

成果摘要

08 已有兼課教師管理介面，可集中追蹤教師名冊、聘期及應備文件。人員分類與聘任關係仍待整理。

工作怎麼做

將教師身分、授課與聘任資料對到同一位教師

  1. 01

    原始資料

    • 全校教職員通訊錄
    • 08 兼課教師名冊
    • 教師總表與班級課表
    • 兼課教師聘任資料與應備文件

  2. 02

    整併與暫行細算

    內部主檔草案（教師主檔、聘任與費率適用、授課資料）

    用固定教師 ID 對齊姓名及別名，再對照聘期、授課與文件。身分分類、聘任關係或費率缺項留待核對。

  3. 03

    報表與交付

    • 08 兼課教師名冊與聘任文件追蹤

    08 已有管理介面。共用主檔仍為草案，正式接入待完成。

加速點　用同一教師 ID 找到授課、聘期及缺件，確認過的姓名與來源可重複引用。

看一筆實際怎麼走

原始通訊錄

同一人出現兩列

主檔整理時比對姓名、別稱及校區關係，確認兩列指向同一位教師。

教師主檔草案

2 列 → 1 個固定教師 ID

合併為同一筆人員資料，保留舊 ID 與別稱供追查。

授課、聘期與文件

依同一 ID 查找缺件

把課表、聘任資料及文件進度對回同一筆。查不到的資料列為待確認。

下一步

先釐清人員分類與不同聘任關係，再複查每類應備文件及進度欄位。
