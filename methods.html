Codex 使用經驗

從本季實作整理出 6 類、24 項技能。帶新手時，可以先練交辦和查證，再試著產出成品、接合流程，最後練習驗收、交接與整理可重用的做法。

交辦與分工取材、查證與整理製作文件、教材與網頁建立工作流程與自動化驗收、發布與接續拆解既有做法與封裝技能Codex 未來技能新手工作指引

David Lin 的網頁如何變成可重用的做法

  1. 盤點交接包裡的文件資料、圖片、網頁模板、建置與比對腳本。
  2. 在工作副本重建總冊，整合金工教室章節，逐章核對差異。
  3. 把空間需求整理與網頁建置寫成兩套 Codex 技能，以章節交接包銜接。
  4. 驗證章節包、網站和技能格式，再核對安裝副本。

技能存檔 school-space-inventory、workbook-web-publisher。

交辦與分工

把工作目標、依據和完成條件說清楚。

  • 任務規格與驗收條件

    交辦時說明要做的成果、可以用的資料、由誰確認，以及什麼算完成。

    實作 校外教學案件先分出填報、收件、課務核對與寄送。 查看 A05 ↗

  • 語音與影像轉寫

    把課堂錄音、會議或影片口述轉成可核對的文字，保留仍須回聽的位置。

    實作 全球中世紀的課堂轉寫支援章節編寫。搬遷影片的口述則轉為分室清冊。 查看 C01 ↗

  • 分支開發與整合

    把可獨立的工作分開做，在整合前確認兩邊使用同一套欄位與驗收案例。

    實作 教師填報工具與教學組收件介面各自建置，再整合測試。 查看 A05 ↗

  • 跨對話工作盤點

    按專案合併多次迭代，記錄成果、決定、待辦與接手位置。

    實作 日常工作回顧與教學組交接紀錄讓下次開工有可追查的起點。 查看 A14 ↗

取材、查證與整理

從多種來源取材，讓每個結果有據可查。

  • 連接器查找與來源定位

    從 Drive、Docs 或 Sheets 定位實際檔案、分頁與欄位，必要時核對原件的版本。

    實作 鐘點費核算把實授、費率依據與月度表件連回各自來源。 查看 A09 ↗

  • 試算表對帳與正規化

    對照欄位、課程代碼和分組規則，將缺資料、差異和已核對項目分開。

    實作 課程代碼與開課資料完成雙向核對，跨年比較另處理重複登錄。 查看 A06 ↗

  • 資料萃取與檔案歸檔

    從文件擷取嵌入圖片或從影片整理清冊，保留來源位置、檔名與核對紀錄。

    實作 課程文稿的 39 張圖片按原圖說歸檔。 查看 C06 ↗

  • 文獻查證與證據索引

    分開原始材料、備查連結和研究推論，記下頁碼、行號或待核對的時間碼。

    實作 青少年課堂敘寫研究逐筆區分已用材料、原始來源及待核對項目。 查看 C02 ↗

製作文件、教材與網頁

依讀者和用途，把原始材料做成可用的成果。

  • 同源多格式輸出

    從同一份內容製作可編修稿、簡報、PDF 或網頁，分開保存編修版與閱讀版。

    實作 家長講座交付現場簡報、講者備忘與可續作檔。 查看 D01 ↗

  • 依範本製表與輸出 PDF

    沿用既有欄位、順序與版面，輸出後核對內容、頁數和閱讀效果。

    實作 鐘點費以同一份細算資料產出不同用途的月度表件。 查看 A09 ↗

  • 圖面、圖表與視覺說明

    把空間、尺寸、設備需求或概念關係轉成可討論的視覺材料，標出假設與待確認事項。

    實作 金工／鐵工教室用情境海報與設備表協助核對分區及動線。 查看 B10 ↗

  • 靜態網站與離線 HTML

    設計章節、導覽與折疊內容，讓教材可在瀏覽器閱讀並保留離線版本。

    實作 全球中世紀以講義、地圖和課堂材料建置章節網頁。 查看 C01 ↗

建立工作流程與自動化

讓常做的作業有固定入口、狀態與交接方式。

  • 工作台介面與狀態設計

    把逐筆核對、草稿、安排、送出與歸檔等階段寫成介面與可回查的紀錄。

    實作 調代課工作台按課次保留安排與通知依據。 查看 A04 ↗

  • 資料契約與介面接合

    定義兩端交換的欄位、必要資料與錯誤回報，讓表單與收件工具可以各自改版。

    實作 校外教學填報和收件端以共同資料規格整合。 查看 A05 ↗

  • 連接器串接與通知讀回

    串接資料查找、草稿、人工確認、寄送與讀回，分開記錄送出與閱讀狀態。

    實作 課程異動通知保留核對依據與實際寄送紀錄。 查看 A04 ↗

  • 排程與增量處理

    指定執行週期、時區、來源及查詢起點，分開處理沒有新資料和來源無法讀取。

    實作 平日 Gmail 早晨簡報依時間範圍整理新增郵件。

驗收、發布與接續

確認成果能用，並留下別人可以重建的版本。

  • 瀏覽器與成品驗收

    逐項檢查導覽、圖片、手機版面、列印和閱讀效果，必要時實際開啟輸出成品。

    實作 全球中世紀教材以章節跳轉、圖片與公開頁讀回驗收。 查看 C01 ↗

  • Git 版本管理與公開發布

    用提交保存版本，核對遠端提交；發布後另從公開網址讀回。

    實作 工作報導將完整審閱稿歸檔，對外版由 GitHub Pages 提供閱讀。

  • 跨裝置交接與完整性檢查

    將來源、成品、接續說明與檔案雜湊打包，解壓後核對能否閱讀或重建。

    實作 《人學》講師材料交接包含離線 HTML、來源索引與接手說明。 查看 D02 ↗

  • 操作環境與錯誤排查

    先辨認檔案、連線、帳號或權限是哪一層出問題，再針對故障範圍處理。

    實作 作品集曾把檔案預覽改為本機 HTTP，解決內嵌瀏覽器的開啟問題。

拆解既有做法與封裝技能

看懂別人的成品如何做出來，再把有效做法留下。

  • 既有網站與交接包拆解

    盤點文件快照、圖片、模板、建置腳本和驗證工具，找出各自的用途與相依關係。

    實作 從 David Lin 的工作總冊網頁與交接包，辨識可重建的來源和流程。 查看 B10 ↗

  • 既有版型重建與章節比對

    在工作副本沿用版型與建置方式，替換指定章節，再比對新版和基準版的章節差異。

    實作 金工教室回填工作總冊時，以章節比對確認指定範圍及受保護內容。 查看 B10 ↗

  • 章節交接規格

    定義交接包要有正文、來源、圖片、變更紀錄與確認狀態，讓內容整理能交給建站流程。

    實作 校舍空間需求與工作總冊網站以共用章節包銜接。 查看 B10 ↗

  • Codex 技能編寫與驗證

    把已驗證的流程寫進 SKILL.md，搭配參考文件及驗證腳本，再以真實案例檢查能否重用。

    實作 已建立並安裝 school-space-inventory 與 workbook-web-publisher，並以金工教室章節和工作總冊驗證。 查看 B10 ↗

新手從零開始的工作指引

用這 24 項實作技能安排自己的第一件 Codex 工作。先練第 1–5 項，第 6–24 項按眼前的任務選學。點技能名稱可回看實作案例。

第一次開工

拿一份手邊的資料完成一件小事。交代目標，找出依據，打開成品核對，再記下下次從哪裡接手。

順序工作項別工作指引
1交辦任務規格與驗收條件說清楚要做什麼、可用哪些資料，以及怎麼判斷完成。
2找資料連接器查找與來源定位先指出原檔、版本和要看的位置。資料在雲端時，再用連接器查找。
3查證文獻查證與證據索引標明依據與待查事項。做研究案時，再細記頁碼、行號或時間碼。
4驗收瀏覽器與成品驗收自己打開交付檔，對照原先要求，確認內容和操作都能用。
5收工交接跨對話工作盤點先記下完成項、待辦和檔案位置。做過幾輪後，再合併不同對話的進度。

遇到材料、成品或交接需求

先看手上的材料和需要交付的格式，再挑對應做法。遇到檔案或環境問題，可以直接跳到第 6 項。

順序工作項別工作指引
6排查問題操作環境與錯誤排查檔案打不開、帳號不對或連線失敗時，先辨認問題出在哪一層。
7錄音與影片語音與影像轉寫要處理錄音、會議或影片口述時，練轉寫、回聽與標記不確定處。
8取圖與清冊資料萃取與檔案歸檔從文件取圖或從影片整理清冊時，保留原檔、檔名和出處。
9試算表試算表對帳與正規化比對兩份表時，先統一欄位與計數規則，再查缺漏和差異。
10表件與 PDF依範本製表與輸出 PDF有固定表格或簽核版式時，沿用範本並打開成品核對。
11視覺說明圖面、圖表與視覺說明需要說清楚空間、數據或概念關係時，用圖呈現並標出待確認處。
12多格式交付同源多格式輸出同一內容要做成講稿、簡報、PDF 或網頁時，先選定共同來源，再輸出各版本。
13網頁靜態網站與離線 HTML成果要用瀏覽器閱讀時，練章節、導覽、圖片和離線開啟。
14存檔與發布Git 版本管理與公開發布反覆改版時先學 Git 存檔。有對外分享需求時，再練發布與讀回驗證。
15換機與交接跨裝置交接與完整性檢查把來源、成品與接續說明一起交付，在另一台電腦確認能否開啟或重建。

工作反覆做或需要串接工具

先把一件實案從頭做到尾。找出反覆出現的狀態和交接點，再決定要做工作台、串接工具或排程。

順序工作項別工作指引
16案件追蹤工作台介面與狀態設計需要逐筆追蹤案件時，先定義草稿、核對、送出和歸檔等狀態。
17資料交換資料契約與介面接合兩個工具要交換資料時，先約定欄位、必填資料和出錯時怎麼回報。
18分工開發分支開發與整合欄位和驗收方式約定好後，把可獨立的部分分開製作，最後整合測試。
19通知流程連接器串接與通知讀回查資料、擬稿和寄送時，逐步核對，由人確認後寄送，再讀回寄送結果。
20定期作業排程與增量處理手動做法已可穩定驗收後，再設定何時執行、從哪裡接著讀新資料。

接手既有成果或保存做法

接到既有成品時，先盤點來源、做出可重建的副本並驗收。想讓同一做法用於下個案件時，再定交接規格和技能。

順序工作項別工作指引
21盤點與拆解既有網站與交接包拆解像 David Lin 的案例，先找出原始資料、圖片、模板、建置和比對工具。
22重建與比對既有版型重建與章節比對在工作副本重建，修改指定章節後，核對哪些內容有變。
23跨流程交接章節交接規格內容整理和網站建置分開接手時，約定正文、圖片、來源和確認狀態。
24技能封裝Codex 技能編寫與驗證做法能重複使用後，再寫成 SKILL.md，並用真實案例驗證能否照著做。
